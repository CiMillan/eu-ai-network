# Europe in the AI network

Applied Network Analysis 2026/27, Group F: Ifeoluwa Adeboye, Sofiia Makhortova, Cintia Millan and Ella Tiihonen.

Who does Europe's AI build on, and who builds on Europe? Nodes are AI models, datasets and apps; a link means one is built on another.

- `PLAN.md`: steps, dates and who does what. **Start here.** `PLAN.pdf` is the same plan as a PDF.
- `proposal/`: the proposal pitch from 2 Nov, `slides.pdf` and `speech.pdf`.
- `data/`: the frozen network and our region tags.
- `notebooks/`: one notebook per step (01 to 06, see `PLAN.md`).
- `app/`: the proposal app, live at https://eu-ai-network.streamlit.app/

Data: Stanford CRFM's Ecosystem Graphs (https://github.com/stanford-crfm/ecosystem-graphs), commit d3c06a4.

Run the app: `pip install -r requirements.txt && streamlit run app/streamlit_app.py`
Notebooks: also `pip install jupyter`.
